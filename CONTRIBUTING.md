# Contribuer

- Ouvrez une issue avant une grosse évolution.
- Une pull request par sujet, avec description claire.
- Ne modifiez jamais les critères officiels (numéro, libellé, nombre). Les ajouts de critères réels doivent citer la source.
- N'ajoutez aucune donnée confidentielle ni matériel d'un client ou employeur.
- Ajoutez l'en-tête SPDX aux nouveaux fichiers (`EUPL-1.2` pour le code, `CC-BY-4.0` pour données et docs).
- Accessibilité : l'outil lui-même doit rester accessible (clavier, contrastes, lecteurs d'écran).
- En contribuant, vous acceptez que votre contribution soit publiée sous la licence du dossier concerné.
