RAWeb 1.1 - Criteria / Critères (number, official title EN, intitulé officiel FR)

Topic 1: Images / Thématique 1 : Images
1.1 EN: Does each image conveying information have a text alternative? FR: Chaque image porteuse d’information a-t-elle une alternative textuelle ?
1.2 EN: Is every decorative image, without a caption, correctly ignored by assistive technologies? FR: Chaque image de décoration, sans légende, est-elle correctement ignorée par les technologies d’assistance ?
1.3 EN: For each image conveying information with a text alternative, is this alternative relevant (excluding special cases)? FR: Pour chaque image porteuse d’information ayant une alternative textuelle, cette alternative est-elle pertinente (hors cas particuliers) ?
1.4 EN: For each image used as a CAPTCHA or test image, with a text alternative, does this alternative make it possible to identify the nature and function of the image? FR: Pour chaque image utilisée comme CAPTCHA ou comme image-test, ayant une alternative textuelle, cette alternative permet-elle d’identifier la nature et la fonction de l’image ?
1.5 EN: For each image used as a CAPTCHA, is there an alternative access solution to the content or to the CAPTCHA function? FR: Pour chaque image utilisée comme CAPTCHA, une solution d’accès alternatif au contenu ou à la fonction du CAPTCHA est-elle présente ?
1.6 EN: Does each image conveying information have, if necessary, a detailed description? FR: Chaque image porteuse d’information a-t-elle, si nécessaire, une description détaillée ?
1.7 EN: For each image conveying information with a detailed description, is this description relevant? FR: Pour chaque image porteuse d’information ayant une description détaillée, cette description est-elle pertinente ?
1.8 EN: In the absence of a replacement mechanism, each image of text conveying information must, if possible, be replaced by styled text. Is this rule respected (excluding special cases)? FR: Chaque image texte porteuse d’information, en l’absence d’un mécanisme de remplacement, doit si possible être remplacée par du texte stylé. Cette règle est-elle respectée (hors cas particuliers) ?
1.9 EN: Is each image caption, if necessary, correctly linked to the corresponding image? FR: Chaque légende d’image est-elle, si nécessaire, correctement reliée à l’image correspondante ?

Topic 2: Frames / Thématique 2 : Cadres
2.1 EN: Does each frame have a frame title? FR: Chaque cadre a-t-il un titre de cadre ?
2.2 EN: For each frame with a frame title, is this frame title relevant? FR: Pour chaque cadre ayant un titre de cadre, ce titre de cadre est-il pertinent ?

Topic 3: Colours / Thématique 3 : Couleurs
3.1 EN: On each web page, the information must not be provided by colour alone. Is this rule respected? FR: Dans chaque page web, l’information ne doit pas être donnée uniquement par la couleur. Cette règle est-elle respectée ?
3.2 EN: On each web page, is the contrast between the colour of the text and the colour of its background sufficiently high (excluding special cases)? FR: Dans chaque page web, le contraste entre la couleur du texte et la couleur de son arrière-plan est-il suffisamment élevé (hors cas particuliers) ?
3.3 EN: On each web page, are the colours used in the user interface components or graphic element conveying information sufficiently contrasting (excluding special cases)? FR: Dans chaque page web, les couleurs utilisées dans les composants d’interface ou les éléments graphiques porteurs d’informations sont-elles suffisamment contrastées (hors cas particuliers) ?

Topic 4: Multimedia / Thématique 4 : Multimédia
4.1 EN: Does each pre-recorded time-based media have, if necessary, a transcript or an audio description (excluding special cases)? FR: Chaque média temporel pré-enregistré a-t-il, si nécessaire, une transcription textuelle ou une audiodescription (hors cas particuliers) ?
4.2 EN: For each pre-recorded time-based media with a synchronised transcript or audio description, are these relevant (excluding special cases)? FR: Pour chaque média temporel pré-enregistré ayant une transcription textuelle ou une audiodescription synchronisée, celles-ci sont-elles pertinentes (hors cas particuliers) ?
4.3 EN: Does each synchronised time-based media have, if necessary, synchronised captions (excluding special cases)? FR: Chaque média temporel synchronisé a-t-il, si nécessaire, des sous-titres synchronisés (hors cas particuliers) ?
4.4 EN: For each synchronised time-based media with synchronised captions, are these captions relevant (excluding special cases)? FR: Pour chaque média temporel synchronisé ayant des sous-titres synchronisés, ces sous-titres sont-ils pertinents (hors cas particuliers) ?
4.5 EN: Does each pre-recorded time-based media have, if necessary, a synchronised audio description (excluding special cases)? FR: Chaque média temporel pré-enregistré a-t-il, si nécessaire, une audiodescription synchronisée (hors cas particuliers) ?
4.6 EN: For each pre-recorded time-based media with a synchronised audio description, is this audio description relevant? FR: Pour chaque média temporel pré-enregistré ayant une audiodescription synchronisée, celle-ci est-elle pertinente ?
4.7 EN: Is each time-based media clearly identifiable (excluding special cases)? FR: Chaque média temporel est-il clairement identifiable (hors cas particuliers) ?
4.8 EN: Does each non-time-based media have, if necessary, an alternative (excluding special cases)? FR: Chaque média non temporel a-t-il, si nécessaire, une alternative (hors cas particuliers) ?
4.9 EN: For each non-time-based media having an alternative, is this alternative relevant? FR: Pour chaque média non temporel ayant une alternative, cette alternative est-elle pertinente ?
4.10 EN: Is each automatically triggered sound controllable by the user? FR: Chaque son déclenché automatiquement est-il contrôlable par l’utilisateur ?
4.11 EN: Is the viewing of each time-based media, if required, accessible and operable by keyboard and any pointing device? FR: La consultation de chaque média temporel est-elle, si nécessaire, contrôlable par le clavier et tout dispositif de pointage ?
4.12 EN: Is the viewing of each non-time-based media accessible and operable by keyboard and any pointing device? FR: La consultation de chaque média non temporel est-elle contrôlable par le clavier et tout dispositif de pointage ?
4.13 EN: Is each time-based media and non-time-based media compatible with assistive technologies (excluding special cases)? FR: Chaque média temporel et non temporel est-il compatible avec les technologies d’assistance (hors cas particuliers) ?
4.14 EN: For each time-based media that has a synchronised caption or audio description track, are the control features for these alternatives presented at the same level as the main features? FR: Pour chaque média temporel qui dispose d’une piste de sous-titres synchronisés ou d’une audiodescription, les fonctionnalités de contrôle de ces alternatives sont-elles présentées au même niveau que les fonctionnalités principales ?
4.15 EN: For each feature that transmits, converts or records pre-recorded synchronised time-based media that has a captions track, are the captions correctly preserved at the end of the process? FR: Pour chaque fonctionnalité qui transmet, convertit ou enregistre un média temporel synchronisé pré-enregistré qui possède une piste de sous-titres, à l’issue du processus, les sous-titres sont-ils correctement conservés ?
4.16 EN: For each feature that transmits, converts or records a pre-recorded time-based media with an audio description, is at the end of the process the audio description correctly preserved? FR: Pour chaque fonctionnalité qui transmet, convertit ou enregistre un média temporel pré-enregistré avec une audiodescription synchronisée, à l’issue du processus, l’audiodescription est-elle correctement conservée ?
4.17 EN: For each pre-recorded time-based media, is the presentation of captions controllable by the user (excluding special cases)? FR: Pour chaque média temporel pré-enregistré, la présentation des sous-titres est-elle contrôlable par l’utilisateur (hors cas particuliers) ?
4.18 EN: For each pre-recorded synchronised time-based media that has subtitles, can these be vocalised (excluding special cases)? FR: Pour chaque média temporel synchronisé pré-enregistré qui possède des sous-titres de traduction synchronisés, ceux-ci peuvent-ils être vocalisés (hors cas particuliers) ?

Topic 5: Tables / Thématique 5 : Tableaux
5.1 EN: Does each complex data table have a summary? FR: Chaque tableau de données complexe a-t-il un résumé ?
5.2 EN: For each complex data table with a summary, is the summary relevant? FR: Pour chaque tableau de données complexe ayant un résumé, celui-ci est-il pertinent ?
5.3 EN: For each layout table, is the linearized content still comprehensible? FR: Pour chaque tableau de mise en forme, le contenu linéarisé reste-t-il compréhensible ?
5.4 EN: For each data table with a title, is the title correctly associated with the data table? FR: Pour chaque tableau de données ayant un titre, le titre est-il correctement associé au tableau de données ?
5.5 EN: For each data table with a title, is the title relevant? FR: Pour chaque tableau de données ayant un titre, celui-ci est-il pertinent ?
5.6 EN: For each data table, are each column header and each row header correctly declared? FR: Pour chaque tableau de données, chaque en-tête de colonne et chaque en-tête de ligne sont-ils correctement déclarés ?
5.7 EN: For each data table, is the appropriate technique used to associate each cell with its headers (excluding special cases)? FR: Pour chaque tableau de données, la technique appropriée permettant d’associer chaque cellule avec ses en-têtes est-elle utilisée (hors cas particuliers) ?
5.8 EN: Each layout table must not use elements specific to data tables. Is this rule respected? FR: Chaque tableau de mise en forme ne doit pas utiliser d’éléments propres aux tableaux de données. Cette règle est-elle respectée ?

Topic 6: Links / Thématique 6 : Liens
6.1 EN: Is every link explicit (except in special cases)? FR: Chaque lien est-il explicite (hors cas particuliers) ?
6.2 EN: On each web page, does each link have an accessible name? FR: Dans chaque page web, chaque lien a-t-il un intitulé ?

Topic 7: Scripts / Thématique 7 : Scripts
7.1 EN: Is each script, if necessary, compatible with assistive technologies? FR: Chaque script est-il, si nécessaire, compatible avec les technologies d’assistance ?
7.2 EN: For each script with an alternative, is this alternative relevant? FR: Pour chaque script ayant une alternative, cette alternative est-elle pertinente ?
7.3 EN: Is each script accessible and operable by keyboard and any pointing device (excluding special cases)? FR: Chaque script est-il contrôlable par le clavier et par tout dispositif de pointage (hors cas particuliers) ?
7.4 EN: For each script that initiates a change of context, is the user warned or does the user have control? FR: Pour chaque script qui initie un changement de contexte, l’utilisateur est-il averti ou en a-t-il le contrôle ?
7.5 EN: On each web page, are status messages correctly rendered (by assistive technologies)? FR: Dans chaque page web, les messages de statut sont-ils correctement restitués par les technologies d’assistance ?

Topic 8: Mandatory elements / Thématique 8 : Éléments obligatoires
8.1 EN: Has each web page a defined document type? FR: Chaque page web est-elle définie par un type de document ?
8.2 EN: For each web page, is the generated source code valid for the specified document type? FR: Pour chaque page web, le code source généré est-il valide selon le type de document spécifié ?
8.3 EN: On each web page, is the default language present? FR: Dans chaque page web, la langue par défaut est-elle présente ?
8.4 EN: For each web page with a default language, is the language code relevant? FR: Pour chaque page web ayant une langue par défaut, le code de langue est-il pertinent ?
8.5 EN: Does every web page have a page title? FR: Chaque page web a-t-elle un titre de page ?
8.6 EN: For each web page with a page title, is this title relevant? FR: Pour chaque page web ayant un titre de page, ce titre est-il pertinent ?
8.7 EN: On each web page, is each language change indicated in the source code (excluding special cases)? FR: Dans chaque page web, chaque changement de langue est-il indiqué dans le code source (hors cas particuliers) ?
8.8 EN: On each web page, is the language code for each language change valid and relevant? FR: Dans chaque page web, le code de langue de chaque changement de langue est-il valide et pertinent ?
8.9 EN: On each web page, tags must not be used only for layout purposes. Is this rule respected? FR: Dans chaque page web, les balises ne doivent pas être utilisées uniquement à des fins de présentation. Cette règle est-elle respectée ?
8.10 EN: On each web page, are changes in reading direction indicated? FR: Dans chaque page web, les changements du sens de lecture sont-ils signalés ?

Topic 9: Information structure / Thématique 9 : Structuration de l’information
9.1 EN: On each web page, is the information structured by the appropriate use of headings? FR: Dans chaque page web, l’information est-elle structurée par l’utilisation appropriée de titres ?
9.2 EN: On each web page, is the document structure consistent (excluding special cases)? FR: Dans chaque page web, la structure du document est-elle cohérente ?
9.3 EN: On each web page, is each list correctly structured? FR: Dans chaque page web, chaque liste est-elle correctement structurée ?
9.4 EN: On each web page, is each quotation correctly indicated? FR: Dans chaque page web, chaque citation est-elle correctement indiquée ?

Topic 10: Presentation of information / Thématique 10 : Présentation de l’information
10.1 EN: In the website, are style sheets used to control the presentation of information? FR: Dans le site web, des feuilles de styles sont-elles utilisées pour contrôler la présentation de l’information ?
10.2 EN: On each web page, is the visible content conveying information accessible to assistive technologies? FR: Dans chaque page web, le contenu visible porteur d’information est-il accessible aux technologies d’assistance ?
10.3 EN: On each web page, does the information remain understandable when the style sheets are deactivated? FR: Dans chaque page web, l’information reste-t-elle compréhensible lorsque les feuilles de styles sont désactivées ?
10.4 EN: On each web page, is the text still readable when the font size is increased by at least 200% (excluding special cases)? FR: Dans chaque page web, le texte reste-t-il lisible lorsque la taille des caractères est augmentée jusqu’à 200 %, au moins (hors cas particuliers) ?
10.5 EN: On each web page, are the CSS declarations for element background and font colours used correctly? FR: Dans chaque page web, les déclarations CSS de couleurs de fond d’élément et de police sont-elles correctement utilisées ?
10.6 EN: On each web page, is each link whose nature is not obvious visible in relation to the surrounding text? FR: Dans chaque page web, chaque lien dont la nature n’est pas évidente est-il visible par rapport au texte environnant ?
10.7 EN: On each web page, for each element receiving keyboard focus, is the focus visible? FR: Dans chaque page web, pour chaque élément recevant le focus du clavier, la prise de focus est-elle visible ?
10.8 EN: For each web page, should hidden content be ignored by assistive technologies? FR: Pour chaque page web, les contenus cachés ont-ils vocation à être ignorés par les technologies d’assistance ?
10.9 EN: On each web page, information must not be conveyed solely by shape, size or location. Is this rule respected? FR: Dans chaque page web, l’information ne doit pas être donnée uniquement par la forme, taille ou position. Cette règle est-elle respectée ?
10.10 EN: On each web page, information must not be conveyed by shape, size or location only. Is this rule implemented appropriately? FR: Dans chaque page web, l’information ne doit pas être donnée par la forme, taille ou position uniquement. Cette règle est-elle implémentée de façon pertinente ?
10.11 EN: For each web page, can the content be presented without any loss of information or functionality and without having to scroll vertically for a window with a height of 256 px or horizontally for a window with a width of 320 px (excluding special cases)? FR: Pour chaque page web, les contenus peuvent-ils être présentés sans perte d’information ou de fonctionnalité et sans avoir recours soit à un défilement vertical pour une fenêtre ayant une hauteur de 256 px, soit à un défilement horizontal pour une fenêtre ayant une largeur de 320 px (hors cas particuliers) ?
10.12 EN: On each web page, can the text spacing properties be redefined by the user without loss of content or functionality (except in special cases)? FR: Dans chaque page web, les propriétés d’espacement du texte peuvent-elles être redéfinies par l’utilisateur sans perte de contenu ou de fonctionnalité (hors cas particuliers) ?
10.13 EN: On each web page, is the additional content appearing when focused or when hovering over a user interface component controllable by the user (excluding special cases)? FR: Dans chaque page web, les contenus additionnels apparaissant à la prise de focus ou au survol d’un composant d’interface sont-ils contrôlables par l’utilisateur (hors cas particuliers) ?
10.14 EN: On each web page, can additional content that appears using CSS styles only be made visible using the keyboard and any pointing device? FR: Dans chaque page web, les contenus additionnels apparaissant via les styles CSS uniquement peuvent-ils être rendus visibles au clavier et par tout dispositif de pointage ?

Topic 11: Forms / Thématique 11 : Formulaires
11.1 EN: Does each form input field have a label? FR: Chaque champ de formulaire a-t-il une étiquette ?
11.2 EN: Is each label associated with a form input field relevant (excluding special cases)? FR: Chaque étiquette associée à un champ de formulaire est-elle pertinente (hors cas particuliers) ?
11.3 EN: In each form, is each label associated with a form input field having the same function and repeated several times in the same page or in a set of web pages consistent? FR: Dans chaque formulaire, chaque étiquette associée à un champ de formulaire ayant la même fonction et répétée plusieurs fois dans une même page ou dans un ensemble de pages est-elle cohérente ?
11.4 EN: In each form, are each field label and its associated field located next to each other (excluding special cases)? FR: Dans chaque formulaire, chaque étiquette de champ et son champ associé sont-ils accolés (hors cas particuliers) ?
11.5 EN: In each form, are the related form controls grouped together, if necessary? FR: Dans chaque formulaire, les champs de même nature sont-ils regroupés, si nécessaire ?
11.6 EN: In each form, does each group of related form controls have a legend? FR: Dans chaque formulaire, chaque regroupement de champs de même nature a-t-il une légende ?
11.7 EN: In each form, is each legend associated with a group of related form controls relevant? FR: Dans chaque formulaire, chaque légende associée à un regroupement de champs de même nature est-elle pertinente ?
11.8 EN: In each form, are the items of the same type in a combobox grouped together in a relevant way? FR: Dans chaque formulaire, les items de même nature d’une liste de choix sont-ils regroupés de manière pertinente ?
11.9 EN: In each form, is the label of each button relevant (excluding special cases)? FR: Dans chaque formulaire, l’intitulé de chaque bouton est-il pertinent (hors cas particuliers) ?
11.10 EN: In each form, is the error management used appropriately (excluding special cases)? FR: Dans chaque formulaire, le contrôle de saisie est-il utilisé de manière pertinente (hors cas particuliers) ?
11.11 EN: In each form, is the error management accompanied, if necessary, by suggestions to help correct input errors? FR: Dans chaque formulaire, le contrôle de saisie est-il accompagné, si nécessaire, de suggestions facilitant la correction des erreurs de saisie ?
11.12 EN: For each form that modifies or deletes data, or transmits answers to a test or examination, or whose validation has financial or legal consequences, can the data entered be modified, updated or recovered by the user? FR: Pour chaque formulaire qui modifie ou supprime des données, ou qui transmet des réponses à un test ou à un examen, ou dont la validation a des conséquences financières ou juridiques, les données saisies peuvent-elles être modifiées, mises à jour ou récupérées par l’utilisateur ?
11.13 EN: Can the purpose of an input field be identified to facilitate the automatic filling of fields with user data? FR: La finalité d’un champ de saisie peut-elle être déduite pour faciliter le remplissage automatique des champs avec les données de l’utilisateur ?

Topic 12: Navigation / Thématique 12 : Navigation
12.1 EN: Does each set of web pages have at least two different navigation systems (excluding special cases)? FR: Chaque ensemble de pages dispose-t-il de deux systèmes de navigation différents, au moins (hors cas particuliers) ?
12.2 EN: In each set of web pages, are the menu and navigation bars always at the same place (except in special cases)? FR: Dans chaque ensemble de pages, le menu et les barres de navigation sont-ils toujours à la même place (hors cas particuliers) ?
12.3 EN: Is the site map page relevant? FR: La page « plan du site » est-elle pertinente ?
12.4 EN: In each set of web pages, is the site map page accessible from an identical functionality? FR: Dans chaque ensemble de pages, la page « plan du site » est-elle accessible à partir d’une fonctionnalité identique ?
12.5 EN: In each set of web pages, is the search engine reachable in the same way? FR: Dans chaque ensemble de pages, le moteur de recherche est-il atteignable de manière identique ?
12.6 EN: Can content grouping blocks present on several web pages (with the exception of the main regions composing the document structure) be reached or avoided, if necessary? FR: Les zones de regroupement de contenus présentes dans plusieurs pages web (à l’exception des zones principales constituant la structure du document) peuvent-elles être atteintes ou évitées, si nécessaire ?
12.7 EN: On each web page, is there a bypass or skip link to the main content region (excluding special cases)? FR: Dans chaque page web, un lien d’évitement ou d’accès rapide à la zone de contenu principal est-il présent (hors cas particuliers) ?
12.8 EN: On each web page, is the navigation sequence consistent? FR: Dans chaque page web, l’ordre de tabulation est-il cohérent ?
12.9 EN: On each web page, navigation must not contain any keyboard traps. Is this rule respected? FR: Dans chaque page web, la navigation ne doit pas contenir de piège au clavier. Cette règle est-elle respectée ?
12.10 EN: On each web page, are keyboard shortcuts using only one key (lowercase or uppercase letter, punctuation, number or symbol) controllable by the user? FR: Dans chaque page web, les raccourcis clavier n’utilisant qu’une seule touche (lettre minuscule ou majuscule, ponctuation, chiffre ou symbole) sont-ils contrôlables par l’utilisateur ?
12.11 EN: On each web page, is the additional content that appears when hovering, focusing or activating a user interface component accessible by keyboard if necessary? FR: Dans chaque page web, les contenus additionnels apparaissant au survol, à la prise de focus ou à l’activation d’un composant d’interface sont-ils si nécessaire atteignables au clavier ?

Topic 13: Consultation / Thématique 13 : Consultation
13.1 EN: For each web page, does the user have control over each time limit modifying the content (excluding special cases)? FR: Pour chaque page web, l’utilisateur a-t-il le contrôle de chaque limite de temps modifiant le contenu (hors cas particuliers) ?
13.2 EN: On each web page, the opening of a new window must not be triggered without user action. Is this rule respected? FR: Dans chaque page web, l’ouverture d’une nouvelle fenêtre ne doit pas être déclenchée sans action de l’utilisateur. Cette règle est-elle respectée ?
13.3 EN: On each web page, does each downloadable office document have an accessible version (excluding special cases)? FR: Dans chaque page web, chaque document bureautique en téléchargement possède-t-il, si nécessaire, une version accessible (hors cas particuliers) ?
13.4 EN: For each office document with an accessible version, does this version offer the same information? FR: Pour chaque document bureautique ayant une version accessible, cette version offre-t-elle la même information ?
13.5 EN: On each web page, is each cryptic content correctly identified? FR: Dans chaque page web, chaque contenu cryptique est-il correctement identifié ?
13.6 EN: On each web page, for each cryptic content having an alternative, is this alternative relevant? FR: Dans chaque page web, pour chaque contenu cryptique ayant une alternative, cette alternative est-elle pertinente ?
13.7 EN: On each web page, are sudden changes in brightness or blinking used correctly? FR: Dans chaque page web, les changements brusques de luminosité ou les effets de flash sont-ils correctement utilisés ?
13.8 EN: On each web page, is every moving or blinking content controllable by the user (excluding special cases)? FR: Dans chaque page web, chaque contenu en mouvement ou clignotant est-il contrôlable par l’utilisateur (hors cas particuliers) ?
13.9 EN: On each web page, can the content be viewed in any screen orientation (portrait or landscape) (excluding special cases)? FR: Dans chaque page web, le contenu proposé est-il consultable, quelle que soit l’orientation de l’écran (portrait ou paysage) (hors cas particuliers) ?
13.10 EN: On each web page, can the features usable or available by means of a complex gesture also be available by means of a simple gesture (excluding special cases)? FR: Dans chaque page web, les fonctionnalités utilisables ou disponibles au moyen d’un geste complexe peuvent-elles être également disponibles au moyen d’un geste simple (hors cas particuliers) ?
13.11 EN: On each web page, can actions triggered by a pointing device on a single point on the screen be cancelled (except in special cases)? FR: Dans chaque page web, les actions déclenchées au moyen d’un dispositif de pointage sur un point unique de l’écran peuvent-elles faire l’objet d’une annulation (hors cas particuliers) ?
13.12 EN: On each web page, can the features that involve movement to or from the device be satisfied in an alternative way (excluding special cases)? FR: Dans chaque page web, les fonctionnalités qui impliquent un mouvement de l’appareil ou vers l’appareil peuvent-elles être satisfaites de manière alternative (hors cas particuliers) ?
13.13 EN: For each document conversion feature, is the accessibility information available in the source document kept in the destination document (excluding special cases)? FR: Pour chaque fonctionnalité de conversion d’un document, les informations relatives à l’accessibilité disponibles dans le document source sont-elles conservées dans le document de destination (hors cas particuliers) ?
13.14 EN: Does each identification or control feature that relies on the use of biological characteristics of the user have an alternative method? FR: Chaque fonctionnalité d’identification ou de contrôle qui repose sur l’utilisation de caractéristiques biologiques de l’utilisateur dispose-t-elle d’une méthode alternative ?

Topic 14: Documentation and accessibility features / Thématique 14 : Documentation et fonctionnalités d’accessibilité
14.1 EN: Does the website's documentation describe the accessibility features available and information relating to compatibility with accessibility? FR: La documentation du site web décrit-elle les fonctionnalités d’accessibilité disponibles et les informations relatives à la compatibilité avec l’accessibilité ?
14.2 EN: For each accessibility feature described in the documentation, the mechanism for enabling an accessibility feature meets the accessibility needs of the users concerned. Is this rule respected (excluding special cases)? FR: Pour chaque fonctionnalité d’accessibilité décrite dans la documentation, le mécanisme qui permet de l’activer répond aux besoins d’accessibilité des utilisateurs concernés. Cette règle est-elle respectée (hors cas particuliers) ?
14.3 EN: Does the website documentation comply with the digital accessibility rules? FR: La documentation du site web est-elle conforme aux règles d’accessibilité numérique ?

Topic 15: Editing tools / Thématique 15 : Outils d’édition
15.1 EN: Does each editing tool allow you to define the accessibility information needed to create content that complies with the digital accessibility rules? FR: Chaque outil d’édition permet-il de définir les informations d’accessibilité nécessaires pour créer un contenu conforme aux règles d’accessibilité numérique ?
15.2 EN: Does each editing tool provide help with creating accessible content that complies with the digital accessibility rules? FR: Chaque outil d’édition met-il à disposition des aides à la création de contenus conformes aux règles d’accessibilité numérique ?
15.3 EN: Does the content generated by each transformation comply with the digital accessibility rules (excluding special cases)? FR: Le contenu généré par chaque transformation des contenus est-il conforme aux règles d’accessibilité numérique (hors cas particuliers) ?
15.4 EN: For each accessibility issue identified by an automatic or semi-automatic accessibility test, does the editing tool provide suggestions for repair? FR: Pour chaque erreur d’accessibilité relevée par un test d’accessibilité automatique ou semi-automatique, l’outil d’édition fournit-il des suggestions de réparation ?

Topic 17: Real-time communication / Thématique 17 : Communication en temps réel
17.1 EN: For each two-way voice communication web application, is the application capable of encoding and decoding this communication with a frequency range whose upper limit is at least 7,000 Hz? FR: Pour chaque application web de communication orale bidirectionnelle, l’application est-elle capable d’encoder et de décoder cette communication avec une gamme de fréquences dont la limite supérieure est de 7 000 Hz au moins ?
17.2 EN: Does every web application that enables two-way voice communication have real-time text communication functionality? FR: Chaque application web qui permet une communication orale bidirectionnelle dispose-t-elle d’une fonctionnalité de communication écrite en temps réel ?
17.3 EN: For each web application that enables two-way voice communication and real-time text, can both modes be used simultaneously? FR: Pour chaque application web qui permet une communication orale bidirectionnelle et écrite en temps réel, les deux modes sont-ils utilisables simultanément ?
17.4 EN: For each real-time text (RTT) functionality, can the messages be identified (excluding special cases)? FR: Pour chaque fonctionnalité de communication écrite en temps réel, les messages peuvent-ils être identifiés (hors cas particuliers) ?
17.5 EN: For each two-way voice communication web application, is there a visual indicator of oral activity? FR: Pour chaque application web de communication orale bidirectionnelle, un indicateur visuel de l’activité orale est-il présent ?
17.6 EN: Does each real-time text communication web application that can interact with other real-time text communication applications comply with the interoperability rules in force? FR: Chaque application web de communication écrite en temps réel qui peut interagir avec d’autres applications de communication écrite en temps réel respecte-t-elle les règles d’interopérabilité en vigueur ?
17.7 EN: For each real-time text communication (RTT) web application, the transmission time for each input unit is 500ms or less. Is this rule respected? FR: Pour chaque application web de communication écrite en temps réel, le délai de transmission de chaque unité de saisie est de 500ms ou moins. Cette règle est-elle respectée ?
17.8 EN: For each telecommunication web application, is it possible to identify the person initiating a call? FR: Pour chaque application web de télécommunication, l’identification de l’interlocuteur qui initie un appel est-elle accessible ?
17.9 EN: For each two-way voice communication web application which makes it possible to identify the activity of a speaker, it is possible to identify the activity of a signer. Is this rule respected? FR: Pour chaque application web de communication orale bidirectionnelle qui permet d’identifier l’activité d’un interlocuteur oralisant, il est possible d’identifier l’activité d’un interlocuteur signant. Cette règle est-elle respectée ?
17.10 EN: For each two-way voice communication web application that has voice-based services, can these be used without the need to listen or speak? FR: Pour chaque application web de communication orale bidirectionnelle qui dispose de fonctionnalités vocales, celles-ci sont-elles utilisables sans la nécessité d’écouter ou parler ?
17.11 EN: For each two-way voice communication web application that has real-time video, is the quality of the video sufficient? FR: Pour chaque application web de communication orale bidirectionnelle qui dispose d’une vidéo en temps réel, la qualité de la vidéo est-elle suffisante ?
